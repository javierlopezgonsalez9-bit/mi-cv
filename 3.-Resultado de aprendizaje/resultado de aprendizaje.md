# Resultado de aprendizaje — Javier López González

a) He entendido las características generales de los lenguajes de marcas
porque en mi currículum he usado etiquetas como <jl:datos_personales> y
<jl:formacion>, las he anidado bien y he separado el contenido de la
estructura.

b) Las ventajas en el tratamiento de la información: al estar todo
estructurado, si una aplicación lee mi XML puede extraer sola mis datos,
mi formación o mis conocimientos, sin tener que rehacer el documento.

c) Lenguajes de marcas que hemos visto en clase:
- XML → sirve para describir y transportar datos estructurados.
- HTML → sirve para estructurar el contenido de una página web.
- JSON → sirve para intercambiar datos entre aplicaciones.
- Markdown → sirve para escribir documentación con formato sencillo.
- SVG → sirve para describir gráficos vectoriales.

d) Ámbitos de aplicación:
- XML → intercambio de datos y documentos.
- HTML → páginas web.
- JSON → APIs y configuración.
- Markdown → documentación.
- SVG → gráficos.

e) XML es de propósito general porque puedo inventarme mis propias
etiquetas según lo que necesite (en mi caso <jl:conocimientos> o
<jl:intereses>).

f) Características propias:
- XML: etiquetas libres, muy estricto con la sintaxis.
- HTML: etiquetas ya definidas, orientado a presentación.
- JSON: pares clave-valor, más corto de escribir.
- Markdown: sintaxis muy simple.

g) La estructura de un documento XML es: primero la declaración, luego
un único elemento raíz (<jl:curriculum>) y dentro los elementos anidados
en orden.

h) Un documento bien formado es el que cumple las reglas básicas de XML
(todo cerrado, una sola raíz...). Válido es además el que respeta un
esquema como mi XSD. Si no está bien formado, ni siquiera se abre.

i) Los espacios de nombres me dejan usar mis propias etiquetas (jl:) sin
que choquen con las de otro vocabulario, y así queda claro que son mías.
